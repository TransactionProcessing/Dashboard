# Dashboard

This repository is the status dashboard for the Transaction Processing ecosystem.
It keeps the same information as the current version, but groups it into cleaner sections with consistent links.

## Jump To

- [Shared Services](#shared-services)
- [Transaction Processing](#transaction-processing)
- [Web Applications](#web-applications)
- [Mobile Applications](#mobile-applications)
- [Support Applications](#support-applications)

Each entry links to release status, build status, quality, issue tracking, and the repository itself through the name link.

## Legend

- `Latest Tag` links to the current release tag badge for each repository.
- `Nightly Build` links to the latest nightly workflow badge where one exists.
- `Coverage` and `Quality` use Codacy badges when available.
- `Issues` and `Pull Requests` link directly to the corresponding GitHub pages.
- `N/A` means the repository does not currently expose that badge or metric here.
